# 家計簿

自分用の家計簿 Web アプリ（HTML / CSS / JavaScript）。

## できること
- 支出の入力（金額・カテゴリ・日付・メモ・タグ）、編集・削除・複数選択して削除
- 履歴の絞り込み（カテゴリ・タグ・メモ検索・期間）
- ホーム：月の合計・前月比・カテゴリ内訳・最近の支出
- 統計：カテゴリ別・タグ別・日別・月別推移のグラフ
- サブスク（定期払い）の登録と、支払日の自動記録

## データについて
データは **Supabase**（クラウドのデータベース）に保存され、スマホと PC で同じデータを使えます。
- メールアドレスとパスワードでログインして使う（新規登録はオフにしてあり、本人しか使えない）
- 表には「ログインした本人の行しか読み書きできない」設定（Row Level Security）をかけている
- 端末にも控えを残すので、オフラインでも閲覧はできる（入力はオンラインのときだけ）
- 以前ブラウザの中（localStorage）に保存していたデータは、ログイン後に一度だけクラウドへ移せる

`js/config.js` の接続先を空にすると、今までどおりブラウザの中だけに保存する動作になります。
`js/config.js` に書くのは公開用（Publishable / anon）キーだけで、管理用のキーは書かないこと。

## ファイル構成
| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `css/style.css` | 見た目（ライト/ダーク、スマホ/PC） |
| `js/config.js` | Supabase の接続先（URL と公開用キー） |
| `js/storage.js` | データの読み書き（クラウド / ブラウザ内）・ログイン・移行 |
| `js/categories.js` | カテゴリの一覧と色 |
| `js/charts.js` | グラフ（Chart.js） |
| `js/subs.js` | サブスクの管理と自動記録 |
| `js/app.js` | 画面の表示と操作 |
| `supabase/schema.sql` | Supabase の表と権限の設定（SQL Editor で実行する） |

## 手元で動かす
`index.html` をブラウザで開くだけで動きます。ローカルサーバーで開く場合：

```
npx.cmd http-server -p 8080 -c-1
```
